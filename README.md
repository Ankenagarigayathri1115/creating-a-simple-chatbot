# Simple Chatbot

A basic rule-based chatbot built using Python.
The chatbot interacts with users through a Command Line Interface (CLI) and responds to simple questions and greetings.

## Features

* Responds to greetings
* Answers simple questions
* Uses if-elif conditions
* Interactive command-line conversation
* Beginner-friendly Python project

## Technologies Used

* Python

## How to Run

1. Install Python on your system
2. Open terminal or command prompt
3. Run the Python file using:

```bash
python chatbot.py
```

## Sample Conversations

User: Hi
Bot: Hello! How can I help you?

User: What is your name?
Bot: I am a simple Python chatbot.

User: Bye
Bot: Goodbye! Have a nice day.

## Purpose of the Project

This project helps beginners understand:

* Conditional statements
* Loops
* User input handling
* Basic chatbot logic in Python
